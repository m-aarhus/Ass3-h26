2 Innledning

Pendling er en viktig del av hvordan arbeidsmarkedet fungerer, og sier mye om hvor folk bor i forhold til der de jobber. I denne oppgaven undersøker vi pendling i kommunene rundt Boknafjorden fra 2002 til 2025. Innledningen bygger på bo- og arbeidsmarkedsregionene som NIBR/TØI publiserte i 2020. Området vi ser på består av seks slike regioner med til sammen 20 kommuner, og størrelsen varierer mye, fra Stavanger/Sandnes med ti kommuner til små regioner i Ryfylke med bare en. Alle kommuner utenfor området samler vi i en gruppe, “resten av landet” (RAL), slik at vi også får med pendlingen inn til og ut av regionen.

Data hentes direkte fra SSB, tabell 03321 og 11616, ved hjelp av en API gjennom pakken PxWebApiData. Et problem underveis er at flere kommuner har blitt slått sammen eller har fått nytt kommunenummer, blant annet ved kommunereformen i 2020. Vi har derfor tilpasset dataene til kommunestrukturen slik den er i 2025, så tallene kan sammenlignes over hele prioden.

Ut fra det lager vi et ryddig datasett med pendlingen mellom kommunene for alle årene. Datasettet bruker vi videre til å lage linjeplot over utviklingen, tabeller over hvor folk fra utvalgte kommuner jobber, og pendlematrisen for noen utvalgte år.

tab_pendlere <- function(data, knr, y = 2003, n = 6) {
  data = filter(data, bkom == knr)
  data = filter(data, !akom %in% c(knr, "k0000"))
  data = filter(data, year(aar) == y)
  data = arrange(data, desc(andel))
  data = head(data, n = n)
  data = select(data, `Place of work` = akom_navn, `Prop. in %` = andel)
  flxtab = as_flextable(data, show_coltype = FALSE, max_row = 30)
  flxtab = delete_part(flxtab, "footer")
  flxtab = theme_booktabs(flxtab)
  flxtab = line_spacing(flxtab, space = 0.3)
}

plot_pendlere <- function(data, knr, grense = 1, lw = 1) {
  data |>

    ungroup() |>
    ggplot(aes(x = aar, y = andel, group = akom_navn, colour = akom_navn)) +
    geom_line(linewidth = lw) +
    labs(x = NULL, y = "Andel i %", colour = "Arbeidssted")
}

Vi lager to funksjoner som skal brukes i resten av oppgaven. tab_pendlere () lager en tabell over kommunene hvor størst andel av de som bor i en valgt kommune jobber. plot_pendlere () lager et linjeplot som viser hvordan disse andelene har utviklet seg over tid. Med funksjonene slipper vi å skrive den samme koden for hver kommune. 

```{r}
tab_pendlere <- function(data, knr, y = 2003, n = 6) {
  data = filter(data, bkom == knr)
  data = filter(data, !akom %in% c(knr, "k0000"))
  data = filter(data, year(aar) == y)
  data = arrange(data, desc(andel))
  data = head(data, n = n)
  data = select(data, `Place of work` = akom_navn, `Prop. in %` = andel)
  flxtab = as_flextable(data, show_coltype = FALSE, max_row = 30)
  flxtab = delete_part(flxtab, "footer")
  flxtab = theme_booktabs(flxtab)
  flxtab = line_spacing(flxtab, space = 0.3)
}

plot_pendlere <- function(data, knr, grense = 1, lw = 1) {
  data |>
    filter(bkom == knr, !akom %in% c(knr, "k0000")) |>
    group_by(akom) |>
    filter(max(andel) > grense) |>
    ungroup() |>
    ggplot(aes(x = aar, y = andel, group = akom_navn, colour = akom_navn)) +
    geom_line(linewidth = lw) +
    labs(x = NULL, y = "Andel i %", colour = "Arbeidssted")
}
```
